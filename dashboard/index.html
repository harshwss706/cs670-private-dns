01 / What this establishes

Real BFV evaluation over a versioned IPv4 snapshot. Cache hits avoid a new PIR transaction. Page grouping prefetches neighboring records.

02 / Privacy boundary

Computational query privacy against an honest-but-curious server. Timing and client IP remain visible. This is not a zero-knowledge proof.

03 / An honest tradeoff

Larger pages can improve cache reuse, but increase response size and evaluation work. A speedup is an experimental question, not a guarantee.
